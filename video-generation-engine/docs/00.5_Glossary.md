# Glossary

> **Version:** 1.0
>
> This document defines the canonical vocabulary used throughout the Video Generation Engine.
>
> Every document, API, database model, and source code module should use these definitions consistently.

---

# Purpose

The Video Generation Engine consists of multiple AI agents, deterministic services, and workflow components.

To prevent ambiguity, every important concept is formally defined here.

---

# Project

A **Project** represents the complete lifecycle of producing a single video.

A Project owns:

- Input script
- Timeline
- Assets
- Workflow state
- Generated media
- Render outputs
- Metadata

Example

```
Project

├── Script
├── Timeline
├── Assets
├── Generated Clips
└── Final Video
```

---

# Script

The human-provided source material.

A script is the primary narrative input to the system.

Example

```
Germany possessed abundant coal,
but lacked domestic oil reserves.
```

The script is immutable.

---

# Timeline

The Timeline is the **single source of truth** for the production process.

It contains every creative decision required to produce the final video.

A Timeline does **not** contain generated media.

Instead, it contains structured planning information.

Example

```
Timeline

↓

Scenes

↓

Shots

↓

Camera Instructions

↓

Asset Strategy

↓

Transitions
```

---

# Scene

A Scene is a logical narrative segment.

Scenes organize the story.

A Scene answers:

> "What part of the story are we telling?"

Example

```
Scene

Germany's Industrial Economy
```

Scenes contain one or more Shots.

---

# Shot

A Shot is the smallest creative planning unit.

A Shot is **not** a video.

A Shot describes:

- intent
- duration
- framing
- camera movement
- transition
- asset strategy

Example

```yaml
intent:
  Show German coal mines

duration:
  3s

camera:
  slow_zoom

strategy:
  historical_search
```

---

# Clip

A Clip is generated media.

Examples

- MP4
- MOV
- WebM

A Clip is the output produced by executing a Shot.

---

# Asset

An Asset is any reusable media resource.

Examples

- photograph
- map
- illustration
- video
- infographic
- document
- audio

Assets may originate from:

- project library
- public archives
- stock providers
- AI generation

---

# Asset Strategy

Defines how a Shot should obtain its visual media.

Possible strategies include

- Search historical archives
- Search project assets
- Search stock libraries
- Generate AI video
- Generate AI image

---

# Director

The Director is an AI planning agent.

Responsibilities

- understand script
- identify narrative
- define pacing
- create scenes

The Director never generates media.

---

# Planner

A Planner is an AI component responsible for enriching the Timeline.

Examples

- Scene Planner
- Shot Planner
- Asset Planner

Each planner transforms one version of the Timeline into another.

---

# Asset Resolver

A deterministic service responsible for locating assets.

Responsibilities

- search
- rank
- download
- validate

It does not make creative decisions.

---

# Provider

A Provider integrates with an external service.

Examples

- OpenAI
- Gemini
- ElevenLabs
- Veo
- Wikimedia
- Pexels

Providers are replaceable.

---

# Renderer

The Renderer assembles the final video.

Responsibilities

- combine clips
- compose images
- synchronize narration
- add captions
- apply transitions
- export video

The Renderer never invents creative decisions.

It only executes the Timeline.

---

# Workflow

A Workflow is the ordered execution of the production pipeline.

Example

```
Script

↓

Timeline

↓

Scenes

↓

Shots

↓

Assets

↓

Rendering

↓

Video
```

---

# Workflow Step

A major phase within a Workflow.

Examples

- Timeline Generation
- Shot Planning
- Asset Resolution
- Rendering

---

# Task

A Task is an executable unit of work.

Tasks may execute in parallel.

Example

```
Generate Clip for Shot 17
```

---

# Command

A Command represents a requested action.

Examples

```
GenerateImage

SearchAssets

RenderVideo

DownloadAsset
```

Commands are deterministic.

---

# Domain Event

A Domain Event records that something has occurred.

Examples

```
TimelineGenerated

ShotPlanned

AssetResolved

RenderCompleted
```

Events describe the past.

Commands request the future.

---

# Creative Context

Shared information available to planning agents.

Includes

- pacing
- tone
- historical period
- audience
- style
- visual language

---

# Human Review

A checkpoint where creative decisions are approved before expensive generation begins.

Human review occurs after Timeline planning.

---

# Render

The process of converting the Timeline and associated media into a final video.

Rendering is deterministic.

---

# Intermediate Representation (IR)

The structured format exchanged between planning agents.

The Timeline is the project's primary Intermediate Representation.

---

# State

The current condition of a Project.

Examples

```
Created

Planning

Generating

Rendering

Completed

Failed
```

---

# Version

Every Timeline modification creates a new version.

Example

```
Timeline v1

↓

Timeline v2

↓

Timeline v3
```

Previous versions remain immutable.

---

# Source of Truth

The authoritative representation of project state.

For this project,

the Timeline is the Source of Truth.

No component should maintain conflicting representations.

---

# Ubiquitous Language

Every engineer, AI agent, API, and document should use these terms consistently.

This glossary is considered authoritative.

If terminology changes, this document must be updated before any implementation changes are made.
