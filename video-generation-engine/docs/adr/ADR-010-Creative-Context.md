# ADR-010

## Title

Shared Creative Context Across Planning Agents

---

## Status

Accepted

---

## Context

Independent planning agents can produce inconsistent creative decisions if they operate without shared context.

Examples include:

- Different visual styles
- Inconsistent pacing
- Conflicting camera language
- Changing narration tone

---

## Decision

All planning agents receive a shared Creative Context.

The Creative Context may contain:

- Original script
- Creator preferences
- Visual style
- Narrative tone
- Color palette
- Camera language
- Historical context
- Timeline generated by previous agents

Agents may enrich the context but should not overwrite existing decisions.

---

## Consequences

Advantages

- Consistent storytelling
- Better visual continuity
- Improved prompting
- Reusable planning context

Disadvantages

- Slightly larger prompt sizes

---

## Future

Creative Context may evolve into persistent project memory shared across multiple videos.
