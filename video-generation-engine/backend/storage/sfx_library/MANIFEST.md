# SFX library

Built 2026-08-20 (motion_new_styles_and_long_form_videos.md §5.5).
Three kinds × 3 short clips, downloaded live from Openverse (Freesound
behind it). Licence gated to CC0 / CC BY. Durations from real `ffprobe`.

Placement is not in this library — the renderer fires a clip of the
matching kind at punch-ins (whoosh), text cards (stinger), and non-cut
transitions.
