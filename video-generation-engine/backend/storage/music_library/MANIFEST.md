# Music library manifest

Built 2026-08-18 (motion_new_styles_and_long_form_videos.md §11, step 6 —
music taxonomy + BPM decision). Two-axis taxonomy per §5.1: **mood**
(content, Director-picked) x **energy** (bedded/mid/driving, preset-picked).
18 cells, 3 tracks each, 54 slots / 53 unique files (one file legitimately
fits two cells - see historical_epic/mid and emotional/driving below).

Every file was downloaded directly from the source below, then verified
with `ffprobe` (real MP3, duration matches the source page) before being
filed here - nothing in this manifest is unverified.

⚠️ = **non-commercial and/or no-derivatives license.** These 8 files are
NOT safe to use in this tool's commercial output as-is - keep them out of
the default selection pool until/unless there's an explicit non-commercial
use case for them. Everything else (Pixabay Content License, CC0, CC BY)
is clear for commercial use.
