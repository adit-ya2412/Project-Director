## Style override: documentary_archival

This project uses the `documentary_archival` style - archival photographs and footage narrating history at a measured, restrained pace, the long-form documentary default. The following overrides the base instructions above where they conflict; everything else (one idea per shot, intent, historical grounding of the `prompt` field) still applies.

- **Camera stays measured - this fragment now carries that instead of a per-project line.** Adding this file switches off the Director's per-project `camera_language` hint for this style: that free-text line (something like "static and slow push, no whip pans") no longer reaches this planner once a style has its own fragment. Keep the base intent→camera table above as your working vocabulary; the substitute for the lost line is simple and fixed rather than per-project: no whip pans, no rapid or jarring moves of any kind. `intensity` stays inside the base prompt's own 0.10-0.25 band on every shot - do not push higher even on an `emphasize` beat; a documentary earns its emphasis from what the shot shows, not from a harder push.
- **Slower shot grammar, if you are told this scene belongs to an act** (an `act:` line appears in the Long-form context block below). A film long enough to have acts is long enough to hold its shots: prefer the coarser end of fragment granularity, combining fragments into one longer shot wherever they still read as one idea, rather than defaulting to the finest possible split. `punch_in` - already rare in the base table for a "slow style" - is off-limits outright here: a hard zoom snap reads as the wrong register once a film is measured in acts rather than seconds. If you are not told this scene belongs to an act, none of this applies; plan the scene as the base prompt and the camera clause above already describe.
- **Visual variety across an act is a real constraint, if you are told this scene belongs to an act.** Ten minutes gives one movement many chances to repeat before it is noticed. Vary which of the permitted moves (`pull_back`, `static`, `slow_push`, `pan`, `split_frame`, `slow_zoom`) carries a given shot rather than letting one dominate a whole act - you cannot see the act's other scenes, so judge only the variety within this one and trust the pattern to hold across the act as a whole.
- **Chapter structure, if you are told this scene opens an act** (the Long-form context block's `opens this act: yes` line). This scene's first shot may carry a `text_card` naming the chapter - use the exact wording from the block's `act:` line, not a paraphrase. Elsewhere, and on every scene not told it opens an act, `text_card` stays exactly as rare as the base prompt already asks for.
- **`fadeblack` is the act-boundary transition, and only that - if you are told this scene opens an act.** Use it as that scene's own first shot's `transition_out`, carrying the chapter card into the chapter's first real image, when there is a second shot to move into. Do not reach for `fadeblack` anywhere else in this style - a scene's own biggest internal turn, years passing, or a place/mood change all still take `dissolve` or `cut` (or a `glitch_*` transition, per the base prompt's own gate, when the scene is genuinely about a signal failing or a deception being exposed). If you are not told this scene opens an act, `fadeblack` is not used in this style at all; use `dissolve` or `cut` for the base prompt's structural-beat moments instead.
