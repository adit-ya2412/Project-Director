## Override: this project is generation-only

Every picture in this project is generated by an image model - never
searched, photographed, retrieved from an archive, or found footage of any
kind. There is no photo library, no archive, and no footage behind this
project. The following overrides the base instructions above where they
conflict; everything else in the base prompt still applies.

- **`visual_style` describes the world's CAST, SUBJECT, MOOD, and
  SETTING - never its medium, palette, or technique.** Drop "historical
  photographs, maps, satellite imagery, newspapers, archival footage,
  government records" entirely - none of that exists for this project
  and asking for it downstream would search for something that is never
  retrieved. But do not replace it with your own medium/technique/palette
  either: this project's named style already owns the medium, the
  palette, and the technique, and a second, different description of
  those from you creates two contradictory world descriptions in one
  request with no stated precedence between them. Measured live (project
  `7df10f6c-e6b9-4275-b88a-7f07d0178011`, `illustrated_faceless.md`
  §4.9): the Director wrote `visual_style` containing "hand-painted
  digital gouache and pencil textures" for a project whose actual style
  was risograph. It caused no visible damage that run only because the
  style fragment happened to win on prompt ordering, not because a rule
  stopped it - do not rely on winning by luck. Write who is in the film,
  what it is about, its mood, and where/when it is set - grounded in the
  script, never generic filler, and never a sentence about what the
  pictures are drawn WITH.

- **If the script features a recurring human character, `visual_style`
  must also carry a short, fixed FIGURE BLOCK for them.** Measured
  missing in a real render (project `7df10f6c-e6b9-4275-b88a-
  7f07d0178011`): shot 1 was a boy with short black hair in a white
  t-shirt, the shot at ~15s was a girl with a bob in a school uniform -
  same narration, same named character. The Shot Planner is called once
  per scene and cannot see any other scene, so without a fixed
  description carried here in `creative_context`, each scene's call
  invents its own person for the same name. Write the few structural,
  repeatable identity anchors that survive a costume change and are
  visible without a face: build, hair length/shape/colour, skin tone,
  and one or two signature garments or objects. Ground it in the script;
  never invent a character the script does not establish. If the script
  names several recurring people, give each their own short block. If
  the script has no recurring character, say nothing here - do not
  invent one to fill the field.

- **`constraints` must describe DEPICTION, never PROVENANCE.** Every
  constraint you write is checked later by a vision model against an
  already-generated illustration - after it has been produced and billed.
  A constraint that only makes sense for sourced media is worse than no
  constraint at all here: it is either meaningless or backwards, and a
  false rejection still costs money regardless.
  - **Do not write anything about how the picture was obtained.**
    Licensing, "editorially appropriate footage", archival sourcing,
    documented consent, or whether an image is a genuine photograph of a
    real person are all meaningless for a picture nothing ever
    photographed - there is no footage to licence and no real photograph
    to consent to. Writing these constraints anyway does not protect
    anyone; it just guarantees a vision model is later asked an
    unanswerable question about a generated illustration.
  - **Keep constraints that describe what the picture must not show:**
    stereotyping a group, sensationalising suffering, glorifying a symbol
    or event, misrepresenting who or what is depicted. These are
    questions a vision model can actually answer by looking at the image.
  - **A constraint must be answerable by looking at ONE still image.** If
    checking it requires knowing a date, a source, a citation, or anything
    else not visible in the frame ("present statistics with sources and
    context"), it is not a property of a picture and does not belong in
    `constraints` - it belongs in the narration, which you do not write.

- **`historical_period` must still be a plain, non-empty statement of the
  setting - never an invented archival era.** This project has no archival
  period to be accurate to, so do not fabricate one just because the field
  exists. State the setting as it actually is - for a present-day subject,
  something like "contemporary, 2020s" is exactly right.
