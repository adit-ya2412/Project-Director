# MVP Success Criteria

The project is considered MVP complete when a user can:

- [ ] Create a project
- [ ] Paste a script
- [ ] Generate a timeline
- [ ] Approve the timeline
- [ ] Resolve assets
- [ ] Generate missing media
- [ ] Render a final MP4
- [ ] Download the completed video
